# Incredible Lavi design examples

[Open the live gallery](https://a2z-open.github.io/incredible-lavi-examples/) · [Download the skill](docs/assets/incredible-lavi.zip)

Four interactive before-and-after pairs covering a game, an equipment website, an incident app and a ferry dispatch board. All four pairs are curated redesigns. The [original skill-guided ferry board](docs/examples/ferry/audit-after.html) preserves the earlier audit.

The source is in `docs/`. Open it locally with `python3 -m http.server 8080 --directory docs`.
